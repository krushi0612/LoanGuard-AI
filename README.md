# 🏦 LoanGuard AI

LoanGuard AI is a Machine Learning based web application for
loan default prediction.

The application uses a trained Logistic Regression model to
estimate the probability of loan default.

---

## 🚀 Features

- 🔮 Loan Default Prediction
- 📊 Dataset Analytics
- 🧠 ML Workflow Explanation
- ℹ️ About Project
- 📬 Contact / Project Information
- 🎨 Modern Streamlit UI
- 📱 Responsive layout

---

## 🤖 Machine Learning

The project uses:

- Logistic Regression
- StandardScaler
- One-Hot Encoding
- Binary Classification

Target:

```text
0 → No Default
1 → Default
